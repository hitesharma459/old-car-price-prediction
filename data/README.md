# Dataset

`car_price.csv` - the dataset supplied for this project (5,512 raw rows, 10 columns).

| Column | Raw format | Used as |
|---|---|---|
| `Unnamed: 0` | row index | dropped |
| `car_name` | "Maruti Swift Dzire VDI" | split into `brand` and `model` |
| `car_prices_in_rupee` | "10.03 Lakh", "1.75 Crore", "80,000" | **target** `price_inr` (rupees) |
| `kms_driven` | "86,226 kms" | `kms_driven` (number) |
| `fuel_type` | Petrol / Diesel / Cng / Lpg / Electric | categorical |
| `transmission` | Manual / Automatic | categorical |
| `ownership` | "1st Owner" ... "5th Owner", "0th Owner" | `ownership` (0-5) |
| `manufacture` | year | `manufacture_year` |
| `engine` | "1956 cc" | `engine_cc` |
| `Seats` | "5 Seats" | `seats` |

`processed/car_price_clean.csv` is generated by `python -m ml.train` (do not edit by hand).
The dataset has no mileage (kmpl), power or location columns, so the app does not ask for them.
